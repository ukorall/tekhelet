# איפה לשים תמונות ואיך לקרוא להן

## הכלל הפשוט

```
content/images/<מזהה-השיטה>/<שם-הקובץ>.jpg
```

זהו. תגרור תמונה לתיקייה של השיטה הנכונה, ואני אמצא אותה אוטומטית - בלי לערוך
JSON, בלי לערוך קוד, בלי לרשום את שם הקובץ בשום מקום.

תומך ב-`.jpg`, `.jpeg`, `.png`, `.webp`.

## שמות קבצים

**אין חובה בשם מסוים** - כל שם יעבוד. אבל אם תרצה שליטה על הסדר שבו הן מוצגות,
אני ממיין לפי סדר אלפביתי, אז כדאי להתחיל במספר:

```
content/images/raavad/01-full.jpg          התמונה הראשית - הגדיל כולו
content/images/raavad/02-closeup.jpg       תקריב של החוליות
content/images/raavad/03-knot.jpg          תקריב של הקשר
```

התמונה הראשונה בסדר היא זו שתופיע קודם, אז שים שם את התמונה שהכי מייצגת.

**שים לב:** התמונה הראשונה של כל שיטה משמשת גם במסך ההכרעה החזותית ("מה הכי יפה
בעיניך"), שם המשתמש משווה בין שיטות זו מול זו. כדאי שהתמונות הראשונות יהיו
בזווית ובתאורה דומות ככל האפשר, אחרת ההשוואה מוטה לטובת מי שצולם יפה יותר.

## גודל

אין הגבלה טכנית, אבל כל התמונות נכנסות לתוך ה-APK - כלומר הן משפיעות ישירות על
גודל ההורדה. בערך 1000-1400 פיקסלים ברוחב זה יותר ממספיק למסך טלפון. אם יש לך
קבצים ענקיים ישר מהמצלמה, שווה להקטין. אם לא בא לך להתעסק - תשלח כמו שהם ואני
אקטין.
