# feedback/

כאן נאספים הפידבקים מבודקי הבטא.

## איך זה עובד

באפליקציה יש מסך "יש לך הערה בשבילי?". כשהבודק לוחץ שלח, נוצר אצלו קובץ JSON
קטן ונפתח חלון שיתוף - הוא שולח לי אותו בוואטסאפ או במייל. אני שומר את הקובץ
כאן ב-`inbox/`, ואז אפשר לעבור על כולם יחד.

**למה לא שליחה אוטומטית לריפו:** כדי לכתוב לגיטהאב מתוך האפליקציה צריך טוקן
גישה בתוך ה-APK. טוקן ב-APK הוא טוקן פומבי - כל מי שמוריד את האפליקציה יכול
לחלץ אותו ולכתוב לריפו. לכן הזרימה עוברת דרכך.

אם בהמשך נרצה אוטומציה מלאה, הדרך הנכונה היא שרת ביניים קטן שמחזיק את הטוקן,
והאפליקציה שולחת אליו. זה אפשרי, אבל זה כבר אומר תשתית מקוונת.

## מה יש בכל קובץ

| שדה | למה |
|-----|-----|
| `text` | ההערה עצמה |
| `kind` | סוג ההערה - טעות בתוכן / באג / ניסוח / חסר / רעיון / כללי |
| `rating` | 1-5, אופציונלי. מאפשר לראות מגמה בלי לקרוא הכל |
| `fromName` | מי שלח, אם מילא |
| `appVersion` | הגרסה המדויקת - כדי לדעת אם זה כבר תוקן |
| `screen` | מאיזה מסך נשלח - כדי למקם את הבעיה |
| `methodId` | איזו שיטה הוצגה באותו רגע, אם רלוונטי |
| `deviceModel`, `androidRelease` | לבאגים שתלויים במכשיר |

השדות האוטומטיים הם מה שחוסך את הסבב של "על מה בדיוק אתה מדבר ובאיזו גרסה".
