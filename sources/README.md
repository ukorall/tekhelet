# תיקיית המקורות

זו הספרייה של הפרויקט. **המיון המקורי נעשה על ידי אוריאל**, ואני לא שיניתי את
המבנה הפנימי שלו - רק סידרתי את מה שהיה בשורש, הסרתי כפילויות, וחילצתי טקסט.

## המבנה

| תיקייה | מה יש שם |
|--------|----------|
| `01-האם/` | הזיהוי והחיוב - האם להטיל תכלת בכלל |
| `02-כמה/` | מספר חוטי התכלת - רמב"ם / ראב"ד / תוספות |

| `04-הלכות/` | ריק בינתיים - גרדומין, שאלות נפוצות |
| `05-כללי/` | מאמרי סקירה, חבורת תכלת תשע"ט, והתרשים |
| `_extracted/` | פלט אוטומטי - ראו למטה. אין כאן מקורות חדשים |
| `_raw/` | ריק. מקום לזרוק לתוכו קבצים בלי למיין |

## מה עשיתי בסבב הזה

**כפילויות מדויקות הוסרו** (חמישה זוגות). ששת הקבצים ששמתי כאן בסבב קודם היו
כולם כפילויות של קבצים מהארכיון שלך, חוץ מאחד. איפה שהשם השני החזיק מידע -
צירפתי אותו: `הרב שמואל טל - זיהוי התכלת (אומדנא דמוכח).pdf`.

**קבצי עזר הוסרו**: נעילות של וורד (`~$...`) ואינדקסים של OneNote (`.onetoc2`),
שאין בהם תוכן. קבצי `.one` עצמם נשארו - יש בהם תוכן שאני לא יודע לקרוא.

**מה שהיה בשורש מוין** לאזור שלו, עם שמות שאומרים מי כתב מה.

## `_extracted/` - מה יש שם ולמה

### `text/` - 60 קבצי טקסט

כל מסמך שאפשר היה, הומר לטקסט חופשי כדי שיהיה אפשר **לחפש** בו. זה לא תחליף
למקור - זה אינדקס.

היה צריך לכתוב לזה כלים: LibreOffice מותקן כאן בלי מסנני המסמכים ולא טוען
אפילו קובץ טקסט. לכן `.doc` נקרא ישירות דרך טבלת ה-piece table
(`tools/doc2txt.py`), ו-`.docx`/`.pptx` נפרסים כ-ZIP.

### תשעה קבצים שלא נקראים כטקסט

הם יוצאו מוורד עם גופן מוטמע ובלי טבלת ToUnicode, ולכן חילוץ טקסט מחזיר
ג'יבריש. **הם קריאים לגמרי כתמונה** - מרנדרים עמוד ב-`pymupdf` וקוראים.

הרשימה: הנשקה (בירורים בקשירת תכלת), קוציו של ארגמון, בין תכלת ללבן, הרב
שמואל טל, הכר נא, מצווה מן המובחר, רמב"ם - הרב טייטלבאום, hagra.

`tools/pdf_glyphmap.py` מנסה לשחזר את המיפוי בהשוואת צורות. הוא מגיע לכ-70%
ולא יותר, ואני מתעד את זה שם במפורש - זה מספיק כדי לחפש מילה, לא כדי לצטט.

### `gadil-photos/` - עשרים תצלומי גדיל

חולצו מהתרשים ומה-SVG. שבעה מהם שויכו לשיטות ועברו ל-`content/images/`
(ראו `content/images/PROVENANCE.md`); השאר מחכים לזיהוי שלך.

## מה שלא נגעתי בו

`.one` (OneNote) ו-`.onetoc2` - אין לי דרך לקרוא אותם. אם יש בהם משהו, יהיה
צריך לייצא אותם.
